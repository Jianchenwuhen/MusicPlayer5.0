\# MusicPlayer5.0 测试说明



\## 测试数据准备



| 数据/环境 | 用途 |

| --- | --- |

| 3 首大于 1 分钟的 MP3 | 验证本地音乐扫描、点击播放、上一首/下一首、播放列表添加 |

| 1 首小于 1 分钟的音频 | 验证本地音乐过滤逻辑 |

| 2 首同名但路径不同的歌曲 | 验证重复歌曲判断和播放列表插入逻辑 |

| 1 个不存在的音频路径 | 验证播放异常路径时 App 不崩溃 |

| 1 首可搜索到同步歌词的歌曲 | 验证歌词加载、LRC 解析和进度同步高亮 |

| 正常网络环境 | 验证在线音乐搜索和歌词接口请求 |

| 断网或弱网环境 | 验证网络异常提示、超时处理和页面稳定性 |

| Android 6.0 及以上设备 | 验证存储权限申请和拒绝权限后的稳定性 |

| Android 8.0 及以上设备 | 验证前台播放服务和通知栏控制 |



建议将测试歌曲放到手机或模拟器的 `Music`、`Download` 目录中，然后重新进入本地音乐页面，让系统媒体库完成扫描。



\## 核心测试用例



| 编号 | 模块 | 测试点 | 操作步骤 | 预期结果 | 优先级 |

| --- | --- | --- | --- | --- | --- |

| TC-MAIN-002 | 主界面 | 页面跳转 | 点击本地音乐、在线音乐、播放列表按钮 | 分别进入对应页面 | P0 |

| TC-MAIN-003 | 主界面 | 无歌曲播放 | 未选择歌曲时点击播放按钮 | App 不崩溃，播放状态不异常 | P0 |

| TC-LOCAL-001 | 本地音乐 | 权限申请 | 首次进入本地音乐页面 | 弹出存储权限申请，授权后正常加载音乐 | P0 |

| TC-LOCAL-002 | 本地音乐 | 拒绝权限 | 拒绝存储权限后进入本地音乐页面 | App 不崩溃，列表为空或保持可操作 | P0 |
